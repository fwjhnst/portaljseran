# Frans Nasution — Landing Page

Landing page profil Frans Nasution yang dibuat dengan Next.js App Router.

## Menjalankan aplikasi

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).

Untuk membuat build produksi:

```bash
npm run build
npm start
```

Konten profil, layanan, tautan media sosial, dan kontak bisa diubah di `app/page.js`. Gaya responsif berada di `app/globals.css`.
